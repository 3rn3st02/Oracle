
 ORACULO

Aplicación Android integrada con una IA RAG en Python.

## Estructura del proyecto

- `android/` → aplicación Android
- `backend/` → backend IA RAG y API
- `docs/` → documentación técnica y funcional
- `shared/` → esquemas y recursos compartidos

## Responsables

- Ernesto: Android e integración con la IA
- Arandeitors: backend IA RAG, API y documentación técnica

## Flujo de trabajo

- No se hace push directo a `main`
- Cada tarea va en una rama
- Todo cambio entra por Pull Request
- Todo cambio de API debe documentarse en `docs/api/`
