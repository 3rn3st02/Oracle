
# Objetivo del proyecto

Desarrollar una aplicación Android que permita al usuario enviar consultas a una IA RAG desarrollada en Python y recibir respuestas desde un backend expuesto mediante API.

## Alcance inicial
- App Android funcional
- Backend IA RAG funcional
- Comunicación mediante API REST
- Documentación clara del contrato de integración

## Roles
- Ernesto: desarrollo Android e integración
- Arandeitors: backend, IA, API y documentación de endpoints
